# 0104 — документация: таблица репозитория в README (M5)

**Запрос.** Пройти раздел «Что в репозитории»: таблица путей с ролями, её заголовок читает сторож
документации (поэтому сторож правится тем же коммитом), плюс сверка фразы о замороженной копии,
которая заявляет замер тремя прогонами. Порядок — актуализировать, сжать, перевести.

**Числа.** README 999 → 1000 строк, кириллицы 486 → **357** (129 русских строк, ровно объём части);
дифф `README.md` 131/130 плюс сторож 3/3 — **267 изменённых строк в двух файлах** при бюджете 600.
Кириллицы в разделе не осталось, следующая кириллическая строка — 548 (уже «Чего ещё нет»).

**Сторож поправлен в том же коммите, и по обеим точкам, где он читал форму.** Он узнавал таблицу по
заголовку `## Что в репозитории` и пропускал строку шапки по слову `Файл`; заголовок теперь
`## What is in the repository`, шапка — `File`, и без второй правки слово «File» попало бы в список
путей и сторож покраснел бы на несуществующем файле. Пути в первых ячейках не тронуты ни одним
символом — переведены только роли, поэтому двусторонняя сверка с деревом осталась той же (проверено
запуском сторожа отдельно: два пункта зелёные).

**Три утверждения оказались неверны, и каждое проверено по коду или замером.**

1. **«Хук `commit-msg` и CI по диапазону»** — у защиты гейт-файлов в CI нет дома вовсе: она не шаг
   профиля (в `tools/gates/gatefiles.js` это сказано прямо), а по диапазону её делает `pre-push` на
   машине, которая отправляет. Та же ложь, что была починена в `AGENTS.md` и в самом `pre-push` на
   прошедших проходах; здесь она осталась в таблице. Теперь названы оба настоящих места.
2. **«Одна на четыре набора»** у обвязки страницы (`tools/page-harness.js`) — замер: файл подключают
   **пять** наборов (`contract-data`, `contract-derived`, `page-view`, `page-tree`, `page-choice`), и
   в его же шапке написано five.
3. **«Тот же полный набор»** у выпуска (`release.yml`) — та же неточность, что я нашёл и починил в
   прозе на проходе M3: работа зовёт строгий линтер, весь набор и проверку тарболла, а не полный
   профиль. Теперь в таблице то, что делает работа.

**Снимок, который стареет, убран:** у манифеста пакета стояла версия `1.2.0` — сегодня `2.4.0`, и
после каждого выпуска она поехала бы снова. Сказано, что манифест держит имя, версию и список
поставки, без числа.

**Замерено, а не пересказано:** таблица обещает «95 строк × 27 колонок» у эталона паритета — сверил по
`fixtures/parity/data.json` (95 и 27 ровно); «бандл фикстуры на 16 коммитов» — по
`fixtures/synthetic/manifest.json` (16 записей, верхушка `16b2fe8`); «55 имён» публичного API — по
списку в `test/api.test.js` (55, посчитал по строкам). Все три совпали, потому что держатся
замороженными файлами и кодом, а не машиной.

**Что отброшено.** Адреса в `REFACTOR.md` (`R-1.5`) и в `BLOCKERS.md` (`§B3`, `§N8`) сняты: оба
документа переписывает этот же подплан, а существо осталось словами. Строка про `src/page/app.js` была
сломана как разметка (не закрыта вертикальной чертой) — починена при переводе. Фраза о замороженной
копии переписана: «проверено тремя прогонами» заменено тем, кто это стережёт сейчас —
`test/git-pins.test.js` показывает незакреплённое чтение свидетелем, `test/environment.test.js` держит
вывод независимым от машины и локали, а slow-профиль повторяет весь набор без настроек git вовсе. Так
заявка на ручной замер превратилась в проверяемое обещание, и это то самое место, которое я оставлял
себе на этот проход.

**Проверено.** `pnpm run verify:fast` зелёный (5 шагов, 72 проверки из 177), полный профиль — зелёный
целиком (8 шагов, 64,0 с). Гейт-файлов в коммите нет (`test/docs-paths.test.js` под шаблон гейтов не
подходит — там только `test/gates-*.test.js`), трейлер не нужен.

**Предложено.** Следующая часть — **M6**: «Чего ещё нет», «Гейт против раздувания», «Для ИИ-агента» и
«Ловушки» (около 94 русских строк). Её тащат уже два читателя сторожа: `tools/docs-facts.js` знает эти
разделы по именам (`NOT_TODAY`, `OWN_PROJECT`), поэтому правка сторожей идёт тем же коммитом. Там же
сверки: список «чего ещё нет» против того, что уже сделано, пороги датчика раздувания против настройки,
и описание контракта `--data` против `src/data.js`.
