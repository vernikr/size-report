# 0094 — проверки: измерения (M10d)

**Запрос.** Пройти часть M10d нарезки — `doctor.test.js`, `minify.test.js`, `check.test.js`,
`guard.test.js`, `tokens.test.js` (153 строки комментариев) — обычными правилами подплана, проверяя
числа и обещания по коду, а не по прежнему тексту.

**Сделано.** `doctor` 275 → 270, `minify` 286 → 285, `check` 261 → 256, `guard` 75 → 72,
`tokens` 195 → 196; 153 строки комментариев дали **295 изменённых строк** (141 добавленная, 154
удалённые) в пяти файлах. Диффом показано: изменены только строки комментариев. Кириллица осталась
лишь внутри данных — имена проверок, тексты утверждений, содержимое файлов фикстуры и строки-образцы,
по которым сверяются сообщения (`/не JavaScript/`, `«skip»`).

**Ложное утверждение — и оно было про внешний источник.** Шапка `tokens.test.js` объявляла, что
якорь «`hello world` = 2 токена — это пример из документации tiktoken, то есть проверка не круговая».
Проверил документацию: tiktoken приводит эту фразу только в примере round-trip (`decode(encode(...))
== "hello world"`) и числа не называет нигде. То есть атрибуция была неверной, а «не круговая» держалась
только на ней. Теперь сказано так, как есть: якоря — числа, написанные рукой для фиксированных текстов,
а не выведенные проверяемым кодом, и с ними можно сверяться любой другой реализацией той же кодировки.
Сами числа подтвердил словарём: 2 токена в обеих кодировках, 5 против 7 на русской строке.

**Три числа, которые уже разошлись.** `guard.test.js` обосновывал грубый порог (300 разборов быстрее
1000 мс) цифрами «отступление стоит 86–97 мс на разбор» и «около 26 с». Измерил сейчас на рабочем
дереве: **70,6 мс** на разбор отступлением и **21,7 с** на 300 разборов — числа уехали на пятую часть, а
порог от них не зависит вовсе. Оставлен порядок цены (десятки миллисекунд на разбор, десятки секунд на
300), а не измерение, которое стареет молча.

**Ещё одно расхождение с кодом.** Шапка `minify.test.js` перечисляла расширения, «за которые отвечает
минификатор», как `.js`, `.mjs`, `.css`. Таблица движка (`MINIFY_LOADERS`) шире: там ещё `.cjs`, `.ts`,
`.mts`, `.cts`, а три названных — просто те, что есть в фикстуре. Единственный источник правды назван
по имени, а перечисление отдано фикстуре.

**И обещание, которого сверка не даёт.** Шапка `doctor.test.js` говорила, что блок покрытия обязан быть
«байт в байт» ответом `size check`. Проверка сравнивает разобранные данные (`deepEqual`), а не байты:
это один ответ в двух местах, а не два его изложения. Теперь так и сказано.

**Что отброшено.** Три адреса в `REFACTOR.md` §3 и сама формула «цена названа в бюджете времени»
(`doctor`, `check`): целей по времени в проекте нет ни у одного профиля — это уже установлено ранее, — а
цена сказана словами («семь состояний, каждое — прогон процесса и проход по истории»; «много прогонов,
по одному на случай»). В `check.test.js` убрано «до сих пор приходилось разбирать руками»: сам класс
вопросов остался, рассказ о прошлом — нет.

**Что сверено измерением и осталось как верное.** `3294a69` — корневой коммит фикстуры и тот, что завёл
`README.md`; коммитов в ней 16 (совпадает с `rep.history.commits === 16`); замер сделан клоном бандла, а
не глазами. Оба замороженных эталона сняты под снятием балласта: в настройках ни одного ключа `minify` —
значит утверждение шапки `minify` верно. `.json` идёт стратегией `compactJson`, а `EXACT_STRATEGIES`
держит только её — поэтому «точность берётся у клеток, а не у названия способа» верно. Общая фраза
починки для «мимо колонок» живёт одна, в `src/config.js`. Оценка по длине идёт по кодовым точкам
(`for (const _ch of text)`), а словарь весит мегабайты (замер: 27 МБ установленного `gpt-tokenizer@4.0.0`).
Внутри покрытия вид обстоятельства выбирается по коду отказа (`e.code === EXIT.SHALLOW ? 'history' :
'config'`), а `WEIGHT` ставит покрытие (1) впереди датчика (4) — полнота важнее точности.

**Проверено.** `git diff`: изменены только строки комментариев; `pnpm run verify:fast` зелёный целиком
(5 шагов, 72 проверки из 177). Эти пять наборов в быстрый прогон не входят (каждому нужен свой клон),
поэтому прогнан полный профиль — зелёный целиком (8 шагов, 75,6 с). Трейлер `Gate-Change:` не
понадобился: гейт-файлов среди правки нет — сверено списком (из тестов там только `test/gates-*.test.js`).
