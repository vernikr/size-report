# 0071 — комментарии точки входа (модуль M1 подплана `comments.md`)

**Запрос.** Пройти первый модуль подплана `comments.md` целиком: `bin/*`, `src/size-table.js`,
`src/cli.js`, `src/args.js`, `src/modes.js`. Датировать утверждения через `git blame`,
отбросить неактуальное, перевести комментарии на английский и сократить до того, что нельзя
вывести из кода этого файла; поведение и код не менять.

**Сделано.** Строк в файле до → после: `src/size-table.js` 94 → 59, `bin/postinstall.js`
51 → 50, `src/cli.js` 87 → 84, `src/modes.js` 181 → 178, `src/args.js` 191 → 191,
`bin/size.js` 6 → 6; модуль 610 → 568, правка — 382 строки в 6 файлах.

**Что отброшено как неактуальное** (каждое проверено против дерева, а не памяти):

- `src/size-table.js`: карта слоёв («кто от кого зависит») — это вывод из самих импортов, её
  считает датчик `deps`; список режимов запуска — второй список к справке (`USAGE` в
  `src/refusal.js`), а живое место одно; ссылка `WORKLOG §19–§21` из кода не открывается.
  Описание метрики `min` как «формы без комментариев и отступов» было **неверным**: по
  умолчанию `minify.engine` — `esbuild`, то есть настоящее сжатие, а снятие балласта —
  отступление (`src/project.js`, `src/metrics.js`).
- `src/modes.js`: режима `--page` больше нет (`MODES` в `src/args.js`); объяснение кода 2 у
  `explain` называло одну причину из трёх — теперь сказано «коммит, который не разрешить»
  (три причины живут в `src/explain.js`).
- `src/cli.js`, `src/args.js`, `bin/*`: текст переписан без рассказа о прошедших заходах;
  причины сохранены — кого называть виновником, почему пустое значение законно только у
  `--init`/`--write` и отказ у `--config`, почему хук ставится здесь, а не в `doctor`.

**Проверено.** `git diff` по модулю: изменены только строки комментариев — ни одной строки
кода; `pnpm run verify:fast` зелёный целиком (5 шагов, быстрый набор 72 из 177); счёт мест
отказа и знаков «✗» в исходниках не поехал (`test/refusals-catalog.test.js`).

**Предложено.** Дальше — M2 (`src/refusal.js`, `src/locales.js`): комментарии только, словари
и тексты отказов — данные, их язык не трогаем. Открытый вопрос плана про выпуск на такую
правку (байты тарболла меняются, поведение — нет) ждёт решения агента mission.
