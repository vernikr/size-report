# 0090 — комментарии синтетической фикстуры (модуль M9f, модуль M9 закрыт)

**Запрос.** Пройти часть M9f подплана `comments.md` — `tools/synthetic/**`, четыре файла, 405 строк —
обычными правилами и тем самым закрыть модуль M9 целиком.

**Сделано.** `content.js` 136 → 135, `history.js` 117 → 116, `note.js` 67 → 67, `repo.js` 85 → 85;
часть 405 → 403, модуль M9 целиком 3698 → 3660 строк. Диффом проверено: 41 добавленная и 43
удалённые строки, и все они — комментарии; единственная «не комментарий по первому символу» строка —
пояснение в конце строки кода (`const d = new Date(...); // …`), где изменён только текст пояснения.
Гейт-файлов здесь нет (в списке защищённых — `tools/gates/`, `tools/suites.js`, `test/gates-*`,
пороги, базы, манифест, lockfile, рабочие процессы, хуки), поэтому трейлер не потребовался — сверено
списком, а не привычкой.

**Главная проверка тут не дифф, а побайтовая сверка фикстуры.** В этих четырёх файлах почти всё —
**данные**: тексты README фикстуры, содержимое её файлов, подписи коммитов, список ловушек и записка,
генерируемая в `fixtures/synthetic/README.md`. Поэтому «данные не тронуты» доказано не глазами, а
прогоном: `pnpm run check:standards` пересобирает фикстуру из этих исходников и сравнивает побайтово —
«4 из 4 файлов побайтово, манифест по полям, бандл несёт 16 коммитов», плюс паритет и бандл живой
истории. Кириллица осталась ровно в двух местах файлов `content.js` — внутри строк, которые
изображают содержимое фикстуры (`// остаток от переезда…` и `// и правят до переименования`), — и это
часть содержимого, а не комментарий.

**Два неверных утверждения, оба в шапке `content.js`.**
1. «У правки названо, какую ловушку она держит». Названы только две правки из девяти: замена символа
   на символ и тройка веток; у `CODE_2`/`CODE_3`/`CODE_4`, у правок старого файла и служебного модуля,
   у заметок и у артефакта пояснений нет вовсе. Осталось то, что верно: правка, у которой ловушка
   своя, называет её над собой.
2. «Путь артефакта — здесь же: он и колонка в настройках, и файл в истории». Колонкой он не является:
   в настройках он `output` (`tools/make-fixture.js`, `output: ARTIFACT`), а колонки — десять подписей
   путей (проверено по `fixtures/synthetic/config.json`: 10 штук, артефакта среди них нет). Заодно
   уточнено, почему пути нельзя разводить: это `output` настроек и файл в истории одновременно.

**Что сверено и осталось как верное.** Арифметика времени (`repo.js`): смещение `+3 * HOUR` над
`Date.UTC(2026, 0, 1, 7, 0, 0)` действительно даёт 10:00 в зоне +03:00, то есть подпись совпадает с
пояснением; `tick` считает вызовы `stamp()`, а он зовётся по разу на коммит, поэтому порядок вызовов
`commit` и есть порядок дат. Список настроек сборки сверен построчно со своим кодом (подписи коммита и
тега сняты, переводы строк не правятся), а закрепления читаются из границы движка (`gitArgv`,
`gitEnv`). Требование слияния с открытой правкой подтверждено своим же кодом: при нулевом коде
слияния функция бросает, то есть фикстура проверяет себя. Счёт «первые восемь коммитов» сходится:
`HISTORY` — восемь записей. Записка действительно сверяется побайтово, и `README.md` в списке
сверяемых файлов, а список ловушек действительно держится человеком — как и список чужих путей у
сторожа документации (`FOREIGN` в `tools/docs-facts.js`), то есть проверка берёт воспроизводимость, а
не верность описания.

**Чего не брал, хотя заметил.** В записке есть ветка предупреждения для случая, когда числа зависят
от локали: она живая (сравнение идёт заново при сборке, `localeStable` считается прогоном с `LC_ALL=C`),
но сегодня не печатается — в манифесте фикстуры стоит `localeStable: true`. Текст этой ветки называет
шаг давно законченного плана, но менять его — значит переснимать фикстуру (её личность — sha коммитов
и хеши файлов), а это решение, а не проход по комментариям. Записано в подплане рядом с M9f.

**Проверено.** `pnpm run verify:fast` зелёный целиком (5 шагов, 72 проверки из 177);
`pnpm run check:standards` зелёный (фикстура пересобрана и совпала побайтово — то есть данные точно
не тронуты). Триггер `Gate-Change:` не понадобился: гейт-файлов среди правки нет.

**Предложено.** Модуль M9 закрыт целиком; следующий по подплану — **M10: проверки** (`test/*.test.js`,
около 6221 строки, план предполагает четыре-пять проходов). Там предмет сверки другой: комментарий в
проверке объясняет не «почему так в коде», а **какой дефект эта проверка ловит** и почему порог или
фикстура взяты именно такие, — и там же лежат два сторожа, которые эту переработку и проверяют
(`docs-*.test.js`, `suites.test.js`), поэтому их комментарии придётся править с оглядкой на то, что
они читают.
