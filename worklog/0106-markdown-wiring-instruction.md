# 0106 — документация: инструкция подключения в README (M7)

**Запрос.** Пройти раздел README «Как подключить к своему проекту», шаги 1–5 (≈157 русских строк):
актуализировать по коду и замеру, сжать, перевести; читателя сторожа документации поправить тем же
коммитом и доказать опытом; исходный код логики не трогать.

**Числа.** README 997 → 990 строк, кириллицы 263 → **106** (ушло 157 русских строк); дифф
`README.md` — 159 удалённых строк с кириллицей и **2 добавленные**, и обе добавленные суть цитаты
вывода инструмента. Плюс `BLOCKERS.md` (заметка N16), `tools/docs-facts.js`, `REFACTOR.md`, `PLAN.md`
и подплан: **412 изменённых строк в шести файлах** при бюджете 600. Следующая кириллическая строка —
779, это шаг 6 (часть M8).

**Опыт со сторожем дал ожидаемый ответ лишь наполовину, и это записано честно.** Ожидание: раздел
перестаёт сниматься из проверки путей (`OWN_PROJECT` в `tools/docs-facts.js`), и сторож краснеет.
Поставил опыт — вернул старое имя раздела: **8 из 8 зелёные**. Причина измерена: пути раздела
(`size-table.config.json`, `docs/size-report.html`, `.github/workflows/size-report.yml`,
`node_modules/@vernikr/size-report/templates/ci.yml`) уже перечислены в `FOREIGN`, поэтому запись лишь
повторяет разрешённое. Переименование всё равно верно — карта называла заголовок, которого больше нет,
— но сегодня эта запись ничего не решает; так и сказано в подплане. Настоящее доказательство опытом дала
другая правка: `readmeCauses` читает строку кода 2 таблицы README и сверяет её с реестром причин слово в
слово, и опыт с переведённой клеткой дал красный («причины отказа совпадают у движка, справки и таблицы
кодов README»).

**Клетка кода 2 осталась русской — это решение, а не недоделка.** Причины отказа суть печатаемый текст
движка (`CONFIG_CAUSES` в `src/refusal.js`), и сторож сравнивает таблицу с реестром дословно. Перевод
этой клетки либо соврал бы, либо потребовал правки движка (перевод печатаемых причин — изменение данных
и поведения). Поэтому клетка **цитируется** как есть, а рядом сказано, почему. Второй русский фрагмент
куска — предупреждение `! таблицу обновляли вместе с кодом: <sha>`: тоже цитата вывода. Это первый
случай, когда критерий подплана «кириллицы не остаётся» упирается в цитату вывода инструмента; решение
то же, что в M11 по вердиктам: печатаемый текст не переводится, а цитируется.

**Три утверждения были неверны.**
1. «Файлом отчёта — `docs/`, если каталог есть»: вилка по существованию каталога снята давно,
   `outputOf()` всегда отдаёт `docs/size-report.html`, а каталог создаёт запись (в `src/project.js`
   сказано, почему вилка была измерена и снята). Замер: в пустом проекте с одним коммитом отчёт лёг
   в `docs/`.
2. Заметка про `size init` говорила «CLI знает только флаги»: команд сегодня шесть (`check`, `explain`,
   `doctor`, `install-hook`, `uninstall-hook`, `hook-run`), а `--init` остался режимом. Переписано по
   справке.
3. «Свой CI у пакета гоняет тот же список команд, что описан ниже»: ниже списка нет, работа гоняет одну
   команду `pnpm run verify`, а список живёт в `tools/gates/run.js`. Заодно снято «его можно взять за
   образец для шага потребителя» — образец это шаблоны.

**Снимки заменены правилами.** Версия в реестре и имя тарболла — правилами без чисел (`pnpm pack`
печатает имя); «установка 3,4 с» убрана (ни один профиль не объявляет цель по времени), осталось чем
это проверено: прогон в пустом проекте без глобальных настроек git и без помощника учётных данных.
История «тег, а не sha» осталась, но назвала источник (`REFACTOR.md` R-4.13) и обошлась без короткого
пина в роли украшения.

**Перемерял и оставил верным.** Реестр отдаёт пакет публично (`npm access get status` → `public`,
тарболл — 200, `npm view ... version` — 2.4.0, как в манифесте); необластное `size-report` занято чужим
пакетом 2017 года (версии 1.0.0–1.0.2; сходится с `PLAN.md` §10); требование «хотя бы один коммит»
(проверено прогонами: без коммита — код 5, с первым коммитом — код 0 и `docs/size-report.html`); вывод
профиля из проекта (колонки — все отслеживаемые измеримые файлы, журнал — первый знакомый, `fixCommand`
— скрипт `sizes` или путь к установленному пакету, метрики `raw`/`min`/`tok`, `min` настоящим сжатием,
`tok` словарём, код 4 без необязательных зависимостей); все двенадцать ключей таблицы настроек; порядок
кодов `doctor` (2, 3, 1, 4) и «непрошеный датчик назван ненужным и не загружается»; описание шаблонного CI
(сборка, сверка с файлом на диске, два снимка чисел и их сравнение); текст подсказки `--init`; причины
`explain` и отказ «коммит вне истории» вместо «нет такого коммита».

**Найдено и записано заметкой.** Репозиторий без единого коммита: `size --write` отвечает **кодом 5** со
стеком (внутренняя ошибка вместо отказа с причиной), хотя `--init` такое состояние переживает намеренно.
Код не трогал — проход документационный: записано **N16 в `BLOCKERS.md`** с воспроизведением, следствием
и тремя вариантами, а README называет требование и ссылается на заметку.

**Проверено.** `pnpm run verify:fast` зелёный (5 шагов, 72 проверки из 177), полный профиль — зелёный
целиком (8 шагов), гейт-файлов в коммите нет (`tools/docs-facts.js` под защиту не подпадает), поэтому
трейлер не нужен.

**Предложено.** Следующая часть — **M8**: шаги 6–8 (хук, ловушки этой же инструкции, уже лежащая копия,
≈104 русских строки). Там свои сверки: обещания хука (что он ставит сам, что коммитит, почему
зацикливание невозможно) и что делать с уже установленной копией инструмента.
