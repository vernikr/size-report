# 0105 — документация: хвост README (M6)

**Запрос.** Пройти хвост README: «Чего ещё нет», «Гейт против раздувания», «Для ИИ-агента» и
«Ловушки», вместе с обоими читателями сторожа (`tools/docs-facts.js`) в том же коммите и с тремя
сверками: список «чего ещё нет» против сделанного, пороги датчика раздувания против настройки,
контракт данных против кода.

**Числа.** README 991 → 997 строк, кириллицы 357 → **263** (94 русских строки — ровно объём части),
дифф: `README.md` 101/103, `tools/docs-facts.js` 1/1, `templates/README.md` 1/1, `REFACTOR.md` 1/1 —
**208 изменённых строк в четырёх файлах** при бюджете 600. Множитель на прозе ≈2,2 изменённой строки
на русскую (у комментариев было 2,0). Кириллицы в пройденных разделах не осталось, следующая
кириллическая строка — 570 («Как подключить к своему проекту», M7).

**Сторож покраснел от переименования, и это доказано опытом в дереве.** `tools/docs-facts.js` знал
два этих раздела по русским именам (`NOT_TODAY`), то есть список «чего ещё нет» попадал в утверждения
о сегодняшнем дне. Поставил опыт: вернул старые имена и прогнал четыре сторожевых файла — **1 из 8
красный**, `docs-commands`, «документация зовёт только существующие команды и ключи»: строка
`size init/measure` из блока «чего ещё нет» читается как вызов инструмента с незнакомой командой.
После правки `NOT_TODAY = ['What is not here yet', 'For an AI agent']` всё зелёное. `OWN_PROJECT`
остался русским: его раздел переводит M7.

**Сверка 1 — список «чего ещё нет» против сделанного. Две строки были неверны.**

1. **`dist/app.js`** стоял как «пре-собранная программа отчёта для публикации» — а решения о нём уже
   нет: раздел готовности выпуска в `PLAN.md` говорит прямо, что файл **не собирается**, потому что
   программа страницы вклеивается в неё при сборке (`src/page/build.js` берёт главы `src/page/*.js` и
   общий расчёт `src/derived.js`), и пре-собранный файл был бы второй копией того же. Теперь строка
   называет это и не обещает того, чего не будет.
2. **`size init/measure`** — «команды вместо ключей» для `measure` неверно даже по форме: команды
   измерения нет вообще, `--init` — режим. Справка (`USAGE`) называет командами только `check`,
   `explain`, `doctor`, `install-hook`, `uninstall-hook`, `hook-run`.
3. Остальные четыре строки проверены по коду и **верны**: блока для агента в шаблонах нет намеренно
   (`templates/README.md`), минификатор разметки не отвечает за HTML и он считается упрощением
   (`MINIFY_LOADERS` — только `js`/`ts`/`css`), JSX и TSX тоже упрощение (там же, с причиной: вывод
   зависит от настройки `jsx` проекта-потребителя), семейство токенов одно — `openai`
   (`TOKEN_FAMILIES`: `gpt-tokenizer`, `o200k_base`/`cl100k_base`), а чужие словари не семья — так
   сказано и в причине отказа. Заодно список переоформлен: метки выровнены, причины перенесены по
   строкам (были строки по 130 символов).

**Сверка 2 — пороги против настройки.** Замер: сложность функции 12, длина 60, модуль 450 строк,
когнитивная 15 (`eslint.metrics.config.js`), база метрик `.eslint-suppressions.json` — `{}`, 3 байта,
то есть «выше порогов ничего не лежит» верно.

**Сверка 3 — контракт данных против кода.** `--json` побайтово равен эталону паритета
(`test/parity.test.js`), `--data` — контракт страницы: абсолютные величины и форма таблицы, ничего
производного (`src/data.js`, а `test/contract-data.test.js` сверяет его с замороженным эталоном
фикстуры и отдельно проверяет отсутствие производных по составу полей). Это добавлено в текст: без
этого строка «контракт страницы» ничего не объясняла. Коды выхода 0–5, «ответ бывает ровно у четырёх
вызовов», уровни находок `action`/`note` и `touched` из `explain` сверены по `USAGE`, `src/doctor.js`
и `src/explain.js` — совпали все.

**Три чужие ссылки указывали на переименованные разделы, и это тоже дефект, а не мелочь.**
`templates/README.md` звал читателя в «Для ИИ-агента», `REFACTOR.md` R-4.11 — в «Чего ещё нет»,
а таблица кодов в самом README (строка кода 5) — в «Ловушки». Все три переведены на новые имена
(`For an AI agent`, `What is not here yet`, `Traps worth testing the engine on`). Строка кодов живёт
внутри ещё русского M7, поэтому в диффе она одна добавляется с кириллицей — это ожидаемо и названо.

**Проверено.** `pnpm run verify:fast` зелёный (5 шагов, 72 проверки из 177), полный профиль — зелёный
целиком (8 шагов, 78,1 с), включая `pack:check` (шаблон `templates/README.md` едет в поставке и
побайтово сверяется) и `check:standards`. Гейт-файлов в коммите нет — правленые сторож и шаблон
гейт-файлами не объявлены (`tools/gates/gatefiles.js` называет `test/gates-*.test.js`, а не документы
и не `tools/docs-facts.js`), поэтому трейлер не нужен.

**Предложено.** Следующая часть — **M7**: «Как подключить к своему проекту», шаги 1–5 (159 русских
строки) и остаток M8 (шаги 6–8). Там же переименование `OWN_PROJECT` в `tools/docs-facts.js` тем же
коммитом: раздел переименовывается, а читатель знает его по имени.
