# 0100 — документация: M2, начало README

**Запрос.** Пройти вторую часть нарезки подплана `markdown.md`: начало README (заголовок и раздел о
состоянии). Порядок шагов — актуализировать каждое утверждение по коду и замерам, затем сжать, затем
перевести; `worklog/**` остаётся русским; часть, по нарезке, правок сторожей не несёт.

**Числа.** README 1139 → 1060 строк, кириллицы 994 → 771 строка: ушло **222 русских строки**, из них
переведено 210 (M2 — 173 плюс проза начала M3 до таблицы прогонов), а 12 удалено вместе с абзацем о
волне 3 (ниже). Дифф: **162 добавленных, 241 удалённая, изменено 403 строки** в одном файле; кириллицы
в правленом диапазоне не осталось ни строки (замер по диффу: удалено 222 строки с кириллицей,
добавлено 0). В бюджете 600 — с запасом. Множитель: 210 переведённых русских строк дали 391 изменённую
(≈1.9), то есть на прозе он ближе к 1.9–2.4, а не ровно 2.4: сжатие срезает часть строк, которых
иначе было бы две.

**Границы частей пришлось уточнить замером.** Нарезка называет M2 = строки 1–190, но абзац о разборе
модуля начинается на строке 186 и кончается на 215, а таблица прогонов стоит не на 229–230, как
записано, а на 227–234: номера в нарезке поставлены по границам абзацев на глаз. Разрезал по шву, а не
по номеру: M2 — до абзаца о разборе модуля, дальше проза M3 до таблицы. Таблица прогонов и её читатель
(`tools/docs-facts.js` `publishedRuns`, который ловит строки по первым словам «Быстрый»/«Полный»)
остались следующему проходу — там же правка сторожа и трейлер.

**Что актуализировано замером.**

1. **Таблица замеров набора убрана целиком** (23,4–29,9 с при 124 проверках, вклад сторожа выпуска
   парным прогоном, +8,5 с на десять проверок хука, «дороже всего — запуски инструмента»). Это снимок
   одного окна: в самом же тексте было сказано, что окна несравнимы, а числа уже разошлись (сегодня
   полный прогон — 59,5 с при 177 проверках). Осталась причина существования разделения и адрес
   измерения: `pnpm run suites:measure` печатает цену каждого файла сам.
2. **Абзац о разборе модуля переписан по коду**: цена стала разовой (рабочий поток на прогон вместо
   процесса на клетку), а измеренные 5,59 → 0,47 с и разброс «отступление стоит 54 мс вместо 86» —
   снимок другой машины и другой истории. Существо осталось: `vm.SourceTextModule` живёт только под
   `--experimental-vm-modules`, а без него гард отступает к `node --check` — медленнее, но не мягче.
3. **Обещания хука/набора сведены к проверяемому**: «ни одна проверка не потеряна и не ослаблена»
   оставлено с указанием, кто это стережёт (`test/suites.test.js`, `test/docs-numbers.test.js`).
4. **Адреса в документы, которые переписывает эта же работа, сняты** (`REFACTOR.md` R-1.1…R-5.5 и §5,
   `PLAN.md`, два адреса в корневой `WORKLOG.md`, которого в корне нет с переезда журнала). Ссылки на
   живые заметки `BLOCKERS.md` (§B1–§B3, §N8) и на `worklog/archive/WORKLOG.md` §18 оставлены: они
   ведут туда, где текст есть.

**Абзац о волне 3 удалён, но его существо восстановлено словами.** В нём были числа снимка («проверок
было 39 и все сохранены», «всего 80»), которые сегодня неверны (177), а вместе с ними — устройство
обвязки. Устройство вернул сжатой формой и сверил по коду: одна обвязка на пакет (`tools/harness.js`),
один клон фикстуры на среду вместо клона на проверку, прогон на чтение не повторяется, правящая
проверка берёт свой клон, файлы идут пулом по ядрам (`tools/run-tests.js`), а числа сходятся: прогон
сверяет число проверок файла с числом объявлений `test(` в нём. Это то же правило подплана — история
остаётся журналу, читателю достаётся то, что верно сейчас.

**Проверено.** `pnpm run verify:fast` зелёный целиком (5 шагов, 72 проверки из 177); полный профиль —
зелёный целиком (8 шагов, 59,5 с), как требует подплан после README. Сторожа, читающие README
(`tools/docs-facts.js` `publishedRuns` / `NOT_TODAY` / `OWN_PROJECT`, `test/docs-numbers.test.js`,
`test/docs-paths.test.js`, `test/docs-commands.test.js`), прошли без правок: таблица прогонов, заголовки
разделов, имена файлов и зовы не тронуты. Гейт-файлов в коммите нет, трейлер не нужен.
