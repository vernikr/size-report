## Что оказалось замыслом, а не фактом (и теперь сказано прямо)
- **Метки версий шагов (`v0.1.0` … `v0.5.0`) не существовали вовсе:** первый выпуск — `1.0.0` 2026-09-14,
  сегодня пакет на **2.4.0**, числа каждого выпуска в `CHANGELOG.md`. Сказано один раз в голове §5.
- **Фикстура — 16 коммитов**, а не «~20»: сходятся манифест и живой `pnpm run check:standards` (4 из 4 файлов
  фикстуры, 3 из 3 живого, бандл на `bd6ef9d`, 149 коммитов). Заморозка названа измерением, а не снимком
  байтов: автор, даты и содержимое зафиксированы, поэтому воспроизводимы sha коммитов, а байты бандла могут
  отличаться между версиями git.
- **`src/size-table.js` — не движок, а точка входа из реэкспортов** (59 строк, ни строки вычислений); механика
  лежит в **15 модулях** (`REFACTOR.md` §R-1.3), команда — `bin/size.js`. Публичный API — **55 имён**, а не 58
  (измерено по `test/api.test.js`, где список заморожен).
- **Замороженной копии в дереве нет:** её байты берутся из истории по требованию и сверяются с записью о
  происхождении эталона (`test/frozen.test.js`). Прежний текст утверждал, что копия лежит в `fixtures/legacy`.
- **Команды `size init/measure/render` не приходили:** сегодняшняя поверхность — режимы `--init`, `--write`,
  `--data` и форма `--json` плюс слова `check`/`explain`/`doctor`/`install-hook`/`uninstall-hook`/`hook-run`
  (§4.7). Режима `--page` (§5, подготовка страницы) не существует вовсе.
- **Пометка честности — не «всё, что не минификация»:** приближение следует из форматов, которые метрика
  действительно держит (`approximateFormats` в `src/metrics.js`), точность стоит у метрики, а по клеткам идёт
  ряд пометок `approx`; второй расчёт на странице закрыт сравнением имён собранной программы с именами
  `src/derived.js` (`test/page-view.test.js`).
- **D3 стерёг не тот файл:** советы отказов исполняет `test/refusals.test.js` (R-4.22), а форма зова — 
  `test/docs-commands.test.js`; `test/cli.test.js` этого не держит.
- **Настройки потребителя сохранили своё имя** (`size-table.config.json` — это `CONFIG_NAME`), а
  `size-report.config.json` — имя **шаблона**; миграции `--migrate` нет; отчёт в git у потребителя **остался**
  (решение R-4.8), вопреки ожиданию шага 2.
