# Subplan: markdown, except the journal

Parent: `plan.md`. Scope: every `.md` in the tree except `worklog/**` (the journal),
`docs/size-report.html` (generated by the tool, owned by the hook) and `fixtures/**`
(frozen data, compared byte for byte).

The task has three parts and they are done in one pass per document, in this order:
**actualize → compact → translate**. Translating first would preserve sentences that are no
longer true; compacting first would hide which claim was dropped.

## Rules

- **English prose.** The numbering and the shapes the documents are read by stay: section
  numbers (`## 4.5.`, `R-4.12`, `- **N8.`), `§` cross-references, table columns.
- **Samples quote the program.** Where a document shows what the tool prints, the sample
  moves to the `en` locale (the config key is `locale`, and `src/locales.js` already holds the
  dictionary) instead of keeping Russian output in an English document.
- **Compact.** A section that retells another document becomes a pointer to it; a paragraph
  that repeats itself becomes a sentence. The repository's own habit — name the reason, drop
  the retelling — is the target style.
- **Actualize against the tree of the day.** Every path, command, flag, number and promise is
  checked with the tree, the help output (`size --help`) or a run. A claim that no longer
  holds is deleted and named in the worklog entry.
- **One document per commit**, `docs: <file> — English and actual`, because the guards read
  these files and the diff has to stay readable.

## Readers that must be edited in the same commit as the document

Translation changes the *shape* the guards look for. The readers are not gate files, so the
edit is allowed — but it belongs in the same diff, never as a silent follow-up.

| Reader | What it looks for | Breaks when |
|---|---|---|
| `tools/docs-facts.js` `publishedRuns` | README run-table rows starting with «Быстрый» / «Полный» | the row words become English |
| `tools/docs-facts.js` `NOT_TODAY`, `OWN_PROJECT` | README section titles «Чего ещё нет», «Для ИИ-агента», «Как подключить к своему проекту» | those headings are renamed |
| `test/docs-paths.test.js` | the README table under the heading `## Что в репозитории` | that heading is renamed |
| `test/docs-commands.test.js` | a bare `§N` resolved to `requirements.md` by the word «требовани» | requirements are quoted without naming the file |
| `tools/docs-facts.js` `DOCS`, `TARGETS`, `FOREIGN` | file *names* (`README.md`, `WORKLOG.md`, …) | a document moves |
| `test/docs-pin.test.js` | the install example `github:vernikr/size-report#<pin>` | never — the pin string comes from `src/tool.js` |
| `test/release.test.js` | steps of `.github/workflows/*.yml` | workflow step names are translated (check before touching) |
| `tools/docs-facts.js` `sectionsOf` | heading and item numbering (`## 4.5.`, `| R-4.12 |`, `- **N8.`) | the numbering scheme is dropped |

## Order, by reader impact

1. `AGENTS.md` — the first thing an agent reads; short, cheap, no guards.
2. `README.md` — the entry point and the largest surface (1137 lines, five guards).
3. `templates/README.md`, `fixtures/live/README.md`, `fixtures/parity/README.md` — notes for
   the consumer and about the frozen fixtures; `pack:check` ships `templates/`.
4. `docs/requirements.md` (216) and `docs/module-design.md` (557) — requirements and the
   design of the move; the second is a document about the past, so it is compacted hard.
5. `BLOCKERS.md` (387) and `REFACTOR.md` (269) — the blocker list and the refactor log.
   Decide per item: a closed blocker is a fact about the past and belongs in the journal; an
   open one stays here.
6. `PLAN.md` (1218) — keep what is still load-bearing (architecture, invariants, boundaries),
   compact or drop the steps of the finished move.
7. `CHANGELOG.md` (690) — the release history. Released numbers are facts and stay; only the
   framing prose is translated and tightened.
8. `docs/plans/**` — already English, kept current as the work advances.

## Definition of done, per document

- English, no stale claim, nothing restated that another document owns; the guard readers
  updated in the same commit.
- `pnpm run verify:fast` green; `pnpm run verify` green after `README.md`, `AGENTS.md`,
  `templates/README.md` and `PLAN.md` (the documents the guards read).
- `wc -l` before/after and the deleted claims recorded in the worklog entry of that turn.
- The whole subplan is done when
  `rg -l '[А-Яа-яЁё]' -g '*.md' -g '!worklog/**' -g '!docs/size-report.html'` finds nothing.
