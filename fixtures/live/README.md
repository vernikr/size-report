# История проекта-потребителя — замороженный бандл

`history.bundle` — история проекта `safe-resets` на ревизии `bd6ef9d`, с которой
снят эталон паритета (`fixtures/parity/manifest.json`). Ветка `main` бандла
указывает ровно на эту ревизию, поэтому клон из него даёт ту же историю, что был у
проекта тогда: 149 коммитов, 95 строк × 27 колонок, `docs/size-table.html` 225 673 Б.

Зачем копия. Проект приватный, и у CI пакета нет к нему ни ключа, ни доступа, а
сверка с живой историей нужна на каждом пуше. Бандл делает её возможной у любого и
без секретов: `pnpm run parity:live` берёт эталон из `fixtures/parity`, а историю
берёт отсюда.

Байты бандла зависят от версии git и нигде не записаны — важно, какую ревизию он
несёт. Это проверяют сами инструменты: `tools/parity-live.js` клонирует бандл и
переключается на ревизию из эталона, а `tools/parity-freeze.js` сверяет собранный
артефакт с блобом из этой же ревизии, поэтому подменить историю и не заметить
этого нельзя.

Пересобирать не нужно: ревизия эталона неподвижна. Если её всё же сдвигают
(`--at <sha>`), бандл пересобирают так:

```bash
git clone --no-hardlinks ../figma/safe-resets /tmp/live
git -C /tmp/live checkout <новая-ревизия>
git -C /tmp/live branch -f main <новая-ревизия>
git -C /tmp/live checkout main
git -C /tmp/live bundle create fixtures/live/history.bundle main
```
