# Зонд 01 — Ориентация

Цель: проверить, за сколько ходов агент с нуля добирается до проверенных ответов
на типовые вопросы о репозитории. Основание: внимание — бюджет (Anthropic,
«Effective context engineering»); прогрессивное раскрытие вместо предзагрузки.

## Протокол

1. Новая сессия агента в корне репозитория. Вставить мета-промпт:

```
Ты впервые в этом репозитории. Отвечай только на основании того, что найдёшь
в файлах; не выдумывай. На каждый вопрос отвечай кратко (1–3 фразы) и указывай
файл, из которого взят ответ. Вопросы:
1. <золотой вопрос 1>
…
N. <золотой вопрос N>
```

2. Для каждого вопроса оценить:

| Баллы | Критерий |
|---|---|
| 2 | Ответ совпадает с эталоном, источник указан верно |
| 1 | Ответ по сути верен, но неполон или источник не указан/неточен |
| 0 | Ответ неверный, выдуманный или «не нашёл» при наличии ответа в репо |

3. Отдельно отметить эффективность: вызовов инструментов на вопрос
   (≤3 — хорошо, 4–6 — средне, ≥7 — навигация плохая).

## Итог зонда

`Ориентация = сумма баллов / (2 × число вопросов) × 100`.

Диагностика: если верные ответы даются только после чтения больших файлов —
знания лежат не в точке входа; если агент цитирует устаревшее — статика пропустила
смысловую протухлость (см. `../README.md`, метрика свежести).
