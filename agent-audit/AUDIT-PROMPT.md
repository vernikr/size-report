# Мета-промпт: аудит силами самого агента

Вставьте этот текст в свежую сессию кодинг-агента в корне целевого репозитория
(комплект `agent-audit/` должен быть доступен — скопируйте каталог или дайте путь).

```
Проведи аудит пригодности этого репозитория для работы ИИ-агентов по комплекту
агент-аудит. Порядок:

1. Статический слой: выполни `bash agent-audit/scan.sh .` и разбери вывод по
   девяти разделам. Не оспаривай числа, но пометь, какие «мёртвые» ссылки —
   примеры из прозы, а какие — настоящие разрывы.
2. Интерпретация: для каждого провала порога сформулируй находку в одну строку:
   метрика → что это стоит агенту (токены, ходы, риск неверного кода) → действие.
3. Точки роста: выбери не более трёх действий с наибольшим рычагом. Приоритет:
   а) неверные команды и ссылки (дезинформация хуже отсутствия);
   б) объявление границ для больших журналов и артефактов (не читать целиком);
   в) сокращение автозагружаемого контекста; остальное — потом.
4. Сформируй скоркарту по шаблону agent-audit/scorecard.md (статическая часть).
5. Ничего не меняй в репозитории без отдельного подтверждения: аудит только
   читает. Изменения предложи списком патчей.

Поведенческие зонды (01–04 в agent-audit/probes/) выполнит человек с чистыми
сессиями; твоя задача — подготовить для них материалы (п.3 из
probes/00-prepare.md): список золотых вопросов, кандидатов в золотые коммиты
и одну провокацию на соблюдение запретов.
```

Ожидаемый артефакт сессии: заполненная скоркарта (статика), список находок,
три точки роста и заготовки для зондов. Человек проверяет, применяет патчи,
перезапускает `scan.sh` и сверяет динамику балла.
